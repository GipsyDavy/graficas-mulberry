1 Introducción y requisitos

Gráficas Mulberry es un sistema de gestión integral diseñado específicamente para talleres de artes gráficas e impresión. Centraliza en una sola aplicación de escritorio todo lo necesario para llevar el negocio: presupuestos, facturas, albaranes, pedidos, stock de materiales, empleados, nóminas, estadísticas y un asistente de inteligencia artificial local.

La aplicación trabaja con una base de datos local SQLite — todos los datos permanecen en tu equipo, sin servidores externos ni suscripciones en la nube.

Requisitos del sistema

ComponenteMínimo recomendado
Sistema operativoWindows 10 / 11 (64 bits)
ProcesadorIntel Core i3 o equivalente
Memoria RAM4 GB (8 GB recomendado para el módulo IA)
Disco duro500 MB libres (más espacio para la base de datos y modelos IA)
JavaIncluido en el instalador (JDK 26)
Ollama (IA)Opcional — se instala desde el propio programa

Instalación

Ejecuta el archivo GraficasMulberry-Instalador-v5.1.0.exe y sigue el asistente. El instalador crea un acceso directo en el escritorio y en el menú de inicio. No requiere privilegios de administrador para el uso diario.

💡
Primera ejecución Al abrir por primera vez la aplicación, ve a Configuración → Mi empresa y rellena los datos de tu empresa. Esta información aparecerá automáticamente en todos los documentos PDF que generes.

Barra lateral de navegación

La barra lateral izquierda contiene todos los módulos del programa. Haz clic en cualquier elemento para cambiar de vista — el elemento activo queda resaltado. El logo y el nombre de la empresa aparecen en la parte superior.

Área de contenido

Ocupa el resto de la pantalla y muestra la vista del módulo seleccionado. Cada módulo tiene su propia barra de herramientas con los botones de acción correspondientes.

En la parte inferior de la barra lateral encontrarás el botón rojo ⏻ Cerrar. Al pulsarlo aparece una confirmación de cierre. Si el módulo de IA (Ollama) está activo, también se detiene al cerrar la aplicación.

ℹ️
Sin pérdida de datos Cada cambio se guarda en la base de datos en el momento en que lo confirmas. No hay un botón de "Guardar todo" global — cada operación es inmediata e individual.

4 Clientes

👥 Clientes

El módulo de Clientes almacena todos los datos de contacto de tus clientes (empresas y particulares). Es el punto de partida para crear presupuestos, facturas y demás documentos, ya que cada documento requiere un cliente asociado.

Tabla de clientes y búsqueda

Al entrar en el módulo, se muestra la tabla con todos los clientes. Las columnas disponibles son:

ColumnaDescripción
NombreNombre de la empresa o del particular.
ApellidosApellidos (para clientes tipo particular).
Tipoempresa o particular.
NIF/CIFIdentificación fiscal.
TeléfonoNúmero de contacto.
EmailCorreo electrónico.
CiudadCiudad del cliente.

Usa la caja de búsqueda situada a la izquierda de la barra de herramientas para filtrar la lista en tiempo real. Puedes buscar por nombre, apellido, NIF o email.

Crear, editar y eliminar clientes

Nuevo cliente

1
Haz clic en el botón + Nuevo (azul).
2
Rellena el formulario. El Nombre es el único campo obligatorio (marcado con *).
3
Selecciona el Tipo: empresa o particular.
4
La ciudad se rellena automáticamente como "Almería". Cámbiala si es necesario.
5
Pulsa Aceptar. El cliente aparece inmediatamente en la tabla.

Los campos del formulario son: Nombre, Apellidos, Tipo (empresa/particular), NIF/CIF, Teléfono, Email, Ciudad, Código Postal, Dirección y Notas.

Editar un cliente

Selecciona el cliente en la tabla y pulsa el botón ✏ Editar (naranja). Se abre el mismo formulario con los datos actuales. Modifica lo que necesites y pulsa Aceptar.

Eliminar un cliente

Selecciona el cliente y pulsa 🗑 Borrar (rojo). Se pide confirmación antes de eliminar.

⚠️
Antes de eliminar Si el cliente tiene presupuestos, facturas u otros documentos asociados, la eliminación puede afectar a esos registros. Considera desactivar o marcar el cliente como inactivo en lugar de borrarlo.

Importar y exportar clientes

Exportar

Pulsa el botón 📤 Exportar. Elige uno de los seis formatos disponibles:

💾SQLiteCopia completa de la base de datos
📊CSVExcel / LibreOffice
🗄️SQLScript de base de datos
{ }JSONDatos estructurados
📄PDFListado imprimible
📝WordDocumento editable .docx

Selecciona el formato y elige dónde guardar el archivo. El nombre del archivo incluye la fecha y hora automáticamente.

Importar

Pulsa 📥 Importar. Selecciona el formato del archivo origen (CSV, SQL o JSON) y elige el archivo. Los clientes importados se añaden o actualizan — si ya existe un cliente con el mismo ID, sus datos serán sobreescritos.

ℹ️
Compatibilidad de importación Solo son compatibles los archivos generados por esta misma aplicación. Para importar datos desde otras fuentes, adapta el formato CSV a las columnas que usa la aplicación.

5 Presupuestos

📋 Presupuestos

El módulo de Presupuestos permite crear, gestionar y hacer seguimiento de las ofertas comerciales que envías a tus clientes. Cada presupuesto puede incluir líneas de servicios/técnicas de impresión y líneas de materiales del stock.

Crear un presupuesto

1
Haz clic en + Nuevo.
2
Selecciona el cliente del desplegable. Si aún no existe, créalo primero en el módulo Clientes.
3
Comprueba el número de presupuesto (se genera automáticamente con el prefijo configurado, p. ej. PRE-0001).
4
Establece la fecha de emisión y la fecha de validez (cuántos días es válida la oferta).
5
Ajusta el % de IVA si es diferente al valor por defecto configurado.
6
Añade las líneas de conceptos (ver sección siguiente).
7
Escribe las notas y condiciones que aparecerán en el PDF.
8
Pulsa Aceptar. El presupuesto se guarda en estado Borrador.

Añadir líneas de concepto

El formulario de presupuesto tiene dos pestañas para añadir conceptos:

Pestaña "Servicios / Técnicas"

Aquí añades los trabajos de impresión. Para cada línea:

  • Selecciona la tarifa del desplegable (cargada desde el módulo Tarifas).
  • Introduce la descripción del servicio.
  • Especifica la cantidad.
  • El precio unitario y el setup se cargan automáticamente de la tarifa, pero puedes modificarlos.
  • El total de la línea se calcula solo.

Pestaña "Materiales del stock"

Aquí añades materiales que se incluirán en el presupuesto:

  • Selecciona el material del desplegable (cargado desde el módulo Materiales).
  • Introduce la cantidad y el precio de venta.
  • El total se calcula automáticamente.
💡
Totales automáticos La base imponible, el importe de IVA y el total con IVA se recalculan al instante cada vez que modificas cualquier línea. No tienes que calcularlos manualmente.

Estados y ciclo de vida

Cada presupuesto tiene un estado que refleja en qué punto del proceso se encuentra:

EstadoSignificado
BorradorRecién creado, aún no enviado al cliente.
EnviadoEntregado al cliente, a la espera de respuesta. Aparece en el KPI del dashboard.
AceptadoEl cliente ha aceptado la oferta.
RechazadoEl cliente ha rechazado la oferta.
FacturadoSe ha generado una factura a partir de este presupuesto.

Para cambiar el estado, selecciona el presupuesto en la tabla y usa el botón ✏ Editar. Cambia el campo de estado y guarda.

Generar PDF y convertir a factura

Generar PDF

Selecciona un presupuesto en la tabla y pulsa el botón 📄 PDF o accede desde el formulario de edición. El PDF incluye los datos de tu empresa (configurados en Configuración → Mi empresa), los datos del cliente, todas las líneas de concepto, los totales con IVA y las condiciones.

Convertir a factura

Cuando un presupuesto es aceptado, puedes convertirlo directamente en factura:

1
Selecciona el presupuesto aceptado en la tabla.
2
Pulsa el botón 🧾 Facturar.
3
Se crea automáticamente una nueva factura con todos los datos del presupuesto. El presupuesto cambia a estado Facturado.

Gestiona todas las facturas emitidas. Puedes crearlas desde cero, a partir de un presupuesto o a partir de un albarán.

Crear una factura

El proceso es idéntico al de los presupuestos. Las columnas de la tabla de facturas son:

PendienteEmitida pero sin cobrar. Aparece en el KPI del dashboard.

Crear albarán desde factura

Para generar el albarán de entrega de una factura:

1
Selecciona la factura en la tabla.
2
Pulsa el botón 📋 Albarán.
3
Se crea un albarán vinculado a esa factura. Puedes verlo y editarlo en el módulo Albaranes.

Crear un pedido

Pestaña: Control de pagos

Esta pestaña es la herramienta de tesorería del programa. Permite registrar los pagos recibidos de cada pedido, incluidos pagos fraccionados.

Registrar un pago

1
Selecciona el pedido en la tabla superior.
2

3
Pulsa + Añadir pago. Introduce la fecha y el importe cobrado.
4
El importe cobrado del pedido se actualiza automáticamente. Si el total coincide con el importe del pedido, el estado cambia a Cobrado.

Fraccionamiento de pagos

Para pedidos con pago en varios plazos, puedes usar la función de fraccionamiento:

1
Selecciona el pedido y pulsa Fraccionar pagos.
2
Indica el número de cuotas y la fecha del primer pago.
3
La aplicación genera automáticamente todas las cuotas con sus fechas de vencimiento.
4
Según se reciban los pagos, márcalos como cobrados.
💡
Pedidos vencidos Los pedidos cuya fecha de vencimiento ha pasado y aún tienen importe pendiente se marcan como Vencidos y aparecen resaltados en rojo. El KPI del dashboard los contabiliza para que nunca se te pase ningún cobro.

9 Tarifas

💰 Tarifas

Las tarifas son los precios unitarios de los servicios de impresión que ofrece tu taller. Se usan como base para calcular el importe de las líneas en presupuestos y facturas.

Técnicas de impresión disponibles

🖨️ Serigrafía
🎨 DTF
🧵 Bordado
🔷 Vinilo
♨️ Sublimación
📐 Gran Formato
📰 Offset

Campos de una tarifa

CampoDescripción
TécnicaTipo de impresión (Serigrafía, DTF, Bordado, etc.).
NombreNombre descriptivo de la tarifa (ej. "Serigrafía 1 color 100 uds.").
Precio unitarioPrecio por unidad producida.
SetupCoste fijo de preparación de la máquina o fotolito.
Mínimo uds.Cantidad mínima de unidades para aplicar esta tarifa.

Uso en presupuestos Cuando creas un presupuesto y seleccionas una tarifa en las líneas de concepto, el precio unitario y el setup se cargan automáticamente. Puedes ajustar los valores para ese presupuesto concreto sin modificar la tarifa original.
ℹ️
Crear varias tarifas por técnica Es habitual tener múltiples tarifas para una misma técnica según el volumen. Por ejemplo, para Serigrafía: "1-50 uds." con un precio, "51-200 uds." con otro precio menor, etc.

10 Materiales

📦 Materiales

El módulo de Materiales controla el inventario de todos los consumibles del taller. Tiene tres pestañas: Stock, Consumo por técnica y Pagos.

Pestaña: Stock

Muestra todos los materiales con su nivel de stock actual. Los materiales cuyo stock está por debajo del mínimo se muestran en rojo.

CampoDescripción
NombreNombre del material.
ReferenciaCódigo o referencia interna.
Categoríatintas, pantallas, sustratos, vinilos, consumibles, bordado.
Stock actualCantidad disponible actualmente.
Stock mínimoNivel de alerta. Si el stock baja de aquí, se marca en rojo y aparece en el KPI del dashboard.
UnidadUnidad de medida (litros, kg, metros, unidades, etc.).
Precio/unidadPrecio de coste por unidad.
ProveedorNombre del proveedor habitual.

Ajuste manual de stock

Para registrar entradas o salidas de material sin que estén ligadas a una producción:

1
Selecciona el material en la tabla.
2
Pulsa el botón + Entrada o − Salida.
3
Introduce la cantidad y un motivo (opcional). El stock se actualiza al instante.

Pestaña: Consumo por técnica

Define las reglas de consumo automático de materiales por técnica de impresión. Por ejemplo: "cada 100 unidades impresas con Serigrafía consume 0,5 litros de tinta negra".

1
Pulsa + Nueva regla.
2
Selecciona la técnica y el material.
3
Introduce la cantidad consumida por lote de producción.
4
Cuando se registre producción de esa técnica, el consumo se descontará automáticamente del stock.

Pestaña: Pagos a proveedores

Registra los pagos realizados a los proveedores de material. Para cada pago puedes registrar:

  • Proveedor, importe y fecha de vencimiento.
  • Estado: pendiente o pagado.
  • Los pagos pendientes con vencimiento próximo aparecen resaltados.
⚠️
Alerta de bajo stock Revisa periódicamente el KPI "Bajo stock" del dashboard. Cuando un material llega al nivel mínimo es el momento de contactar con el proveedor para reponerlo a tiempo y evitar interrupciones en la producción.

12 Nóminas

💼 Nóminas

El módulo de Nóminas calcula y gestiona las retribuciones de los empleados según la normativa laboral española vigente.

Cálculo automático

Al crear una nómina, la aplicación calcula automáticamente todos los conceptos a partir del salario bruto del empleado:

ConceptoDescripción
Salario brutoBase de cotización (tomado de la ficha del empleado).
Cotización SS trabajadorCuota de Seguridad Social a cargo del trabajador (~6,35%).
Retención IRPFRetención fiscal según el % configurado en la ficha.
Salario netoLo que recibe el trabajador: bruto − SS − IRPF.
Coste empresaCoste total para la empresa: bruto + cuota patronal SS (~30%).

Los valores se recalculan en tiempo real mientras editas los campos. Puedes ajustar manualmente cualquier valor antes de guardar.

Crear una nómina individual

1
Pulsa + Nueva nómina.
2
Selecciona el empleado del desplegable.
3
Introduce el período (mes y año).
4
Revisa los importes calculados automáticamente.
5
Pulsa Aceptar.

Generación masiva de nóminas

Para generar la nómina de todos los empleados activos en un solo paso:

1
Pulsa el botón ⚡ Generar todas.
2
Indica el período para el que quieres generar las nóminas.
3
La aplicación crea automáticamente una nómina por cada empleado activo.
ℹ️
Aviso legal Este módulo realiza cálculos orientativos basados en los porcentajes de cotización a la Seguridad Social vigentes. Para nóminas con convenio colectivo, horas extra, complementos o situaciones especiales, consulta con un gestor laboral.

13 Estadísticas

📊 Estadísticas

El módulo de Estadísticas ofrece un análisis visual completo del negocio. Dispone de un selector de año en la parte superior para filtrar todos los gráficos, y un botón 📄 Exportar PDF para guardar el informe.

Se organiza en cuatro pestañas:

Tab Financiero

Muestra los indicadores económicos clave:

  • KPIs principales: total facturado, cobrado, pendiente y gastos de materiales del año.
  • Gráfica de ingresos vs gastos: comparativa mensual en barras.
  • Facturación acumulada: línea de progreso durante el año.
  • Estado de facturas: distribución en tarta (pendiente, pagada, vencida, anulada).
  • Estado de presupuestos: distribución en tarta (borrador, enviado, aceptado, rechazado, facturado).

Tab Materiales

  • Top 10 materiales más consumidos: gráfica de barras horizontal.
  • Consumo por categoría: tintas, vinilos, pantallas, etc.
  • Stock actual: comparativa de stock actual vs stock mínimo para cada material.

Tab Clientes

  • Nuevos clientes por mes: cuántos clientes nuevos se han dado de alta cada mes.
  • Clientes por tipo: proporción empresa vs particular.
  • Top 8 clientes por facturación: los clientes que más han facturado en el año seleccionado.

Tab Producción

  • Ingresos por técnica de impresión: cuánto ha facturado cada técnica (Serigrafía, DTF, Bordado, etc.).
  • Volumen de producción: unidades producidas por técnica.
  • Estado de pedidos: activos, completados, vencidos.
💡
Exportar el informe Pulsa el botón 📄 Exportar PDF para generar un informe en PDF con todos los gráficos y datos del año seleccionado. Útil para reuniones o para guardar como registro anual.

14 Asistente IA

🤖 Asistente IA

El módulo de Asistente IA integra un chatbot local impulsado por Ollama. Toda la inteligencia artificial funciona completamente en tu equipo, sin enviar ningún dato a internet ni a servidores externos.

Requisitos previos

Para usar el asistente necesitas tener Ollama instalado. Si no lo tienes:

1
Al entrar en la vista, si Ollama no está detectado aparece el botón ⬇ Instalar Ollama.
2

💡
Privacidad total Al ser un modelo local, puedes consultar información confidencial del negocio (precios, clientes, estrategias) sin preocuparte por la privacidad. Ningún dato sale de tu ordenador.

16 Importar Backup

Este módulo permite restaurar una copia de seguridad completa de la aplicación o importar datos desde un archivo externo.

🚨
¡Atención! Esta operación reemplaza todos los datos actuales Al importar un backup completo (SQLite, SQL o ZIP de CSV), los datos existentes en la aplicación serán reemplazados completamente por los del archivo importado. Esta acción no se puede deshacer. Haz siempre una exportación previa antes de importar.

Formatos de importación

💾SQLite (.db)Copia completa de la base de datos
🗜️CSV (.zip)Carpeta comprimida con todos los CSV
🗄️SQL (.sql)Script de volcado de base de datos
{ }JSON (.json)Datos en formato JSON estructurado

Cómo restaurar una copia

Elige el formato del archivo que vas a importar.

Selecciona el archivo en el explorador de archivos.

17 Exportar / Backup

💾 Exportar / Backup

Este módulo permite crear copias de seguridad completas de toda la aplicación y exportar los datos en varios formatos.

Formatos disponibles

FormatoDescripciónUso recomendado
💾 SQLite (.db) Copia exacta de la base de datos completa. Backup principal. Para restaurar en otro equipo o reinstalación.
🗜️ CSV (.zip) Todas las tablas exportadas en archivos CSV comprimidos. Para analizar datos en Excel o LibreOffice.
🗄️ SQL (.sql) Script SQL con la estructura y todos los datos. Para desarrolladores o migración a otro gestor de BD.
{ } JSON (.json) Todos los datos en formato JSON. Para integración con otras aplicaciones o backups de datos.

Crear una copia de seguridad

1
Selecciona el formato de exportación.
2
Pulsa Exportar.
3
Elige la carpeta de destino. El nombre del archivo incluye la fecha y hora automáticamente (ej. GraficasMulberry_Backup_20260501_143022.db).
4
Una vez completada, puedes abrir la carpeta directamente pulsando el botón 📂 Abrir carpeta.
💡
Hábito recomendado Realiza un backup en formato SQLite al menos una vez a la semana. Guarda los archivos en una unidad externa o en la nube (Google Drive, OneDrive) para protegerte ante un fallo del equipo.
ℹ️
Registro de exportaciones El módulo mantiene un registro con la fecha, hora y tipo de cada exportación realizada. Puedes consultarlo para saber cuándo fue la última copia.

+ Flujo de trabajo típico

A continuación se describe el flujo de trabajo más habitual en un taller de artes gráficas usando la aplicación:

1
Alta del cliente
El cliente contacta con el taller. Ve a Clientes → + Nuevo y registra sus datos.
2
Crear presupuesto
En Presupuestos → + Nuevo, selecciona el cliente, añade las líneas de trabajo (técnica + materiales) y envíalo. Cambia el estado a Enviado.
3
Confirmación del cliente
Si acepta: cambia el estado a Aceptado. Si rechaza: Rechazado.
4
Convertir a factura
Con el presupuesto aceptado seleccionado, pulsa Facturar. Se genera automáticamente la factura correspondiente.
5
Crear albarán
Cuando el trabajo está listo para entregar, crea el albarán desde la factura. Entrega el trabajo y cambia el estado a Entregado.
6
Registrar el cobro
En Pedidos → Control de pagos, registra el pago recibido. Si es en varios plazos, usa el fraccionamiento de pagos.
7
Actualizar stock
Si consumiste materiales para el trabajo, ve a Materiales → Stock y ajusta las cantidades.
8
Revisar estadísticas
Periódicamente consulta Estadísticas para ver la evolución del negocio.
