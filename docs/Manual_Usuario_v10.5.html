Manual completo de usuario

Guía paso a paso de Gráficas Mulberry v10.5, organizada por pantalla y módulo. Cada apartado explica cómo acceder, qué contiene, cómo crear, editar, borrar, previsualizar, imprimir, importar y exportar cuando la función existe en esa pantalla.

VERSIÓN 10.5
GM

1Objetivo y forma correcta de usar este manual

Este manual está escrito para el usuario final. La estructura sigue el recorrido real dentro de la aplicación: primero se explica cómo entrar y moverse; después se documenta cada módulo en su propio apartado; por último se explican herramientas transversales como IA, copias, importaciones, columnas dinámicas y vista previa PDF.

Cuando una acción se repite en varios módulos, se vuelve a explicar dentro del módulo correspondiente. Esto evita que el usuario tenga que saltar a otra parte del manual para saber cómo crear, editar, borrar, imprimir, importar o exportar desde la pantalla en la que está trabajando.

Datos locales.
La información de trabajo se guarda en una base de datos SQLite local en %LOCALAPPDATA%\GraficasMulberry\graficas_mulberry.db. Para protegerla, usa Exportar / Backup de forma periódica.

2Arranque, navegación y acceso a pantallas

Abrir la aplicación

  1. Abre Gráficas Mulberry desde el acceso directo de Windows o desde el menú Inicio.
  2. Espera a que aparezca el panel principal. La aplicación entra directamente al entorno de trabajo.
  3. Comprueba la versión visible en la interfaz: v10.5.0.
  4. Antes de trabajar por primera vez, entra en Configuración y revisa datos de empresa, preferencias y copias.

Acceder a un módulo

  1. Localiza el menú lateral.
  2. Elige el grupo correspondiente: Clientes, Comercial, Almacén, Personal, Analítica o Sistema.
  3. Haz clic en el módulo deseado.
  4. Comprueba el título superior de la pantalla cargada.
  5. Trabaja en el área central o abre el módulo en ventana aparte si necesitas compararlo con otra pantalla.

Abrir un módulo en ventana aparte

  1. Abre el menú contextual del botón del módulo.
  2. Selecciona Abrir en ventana aparte.
  3. La pantalla se abre en una ventana independiente.
  4. Usa esta opción para consultar datos sin abandonar la pantalla central.
  5. Si quieres volver al área principal, usa Abrir en área principal.
Área principalZona central donde se carga el módulo seleccionado.
Ventana aparteVentana independiente para comparar o consultar otro módulo.
SalirCierra la aplicación y libera servicios auxiliares.

3Acciones comunes en tablas, formularios y documentos

Seleccionar y leer una tabla

  1. Abre el módulo que contiene la tabla.
  2. Lee los encabezados de columnas para saber qué dato representa cada una.
  3. Usa Buscar para filtrar por texto visible.
  4. Haz clic sobre una fila para seleccionarla.
  5. Antes de pulsar Editar, Borrar, PDF o Exportar, confirma que la fila seleccionada es la correcta.
  6. Si no ves una columna, pulsa Columnas y comprueba si está oculta.

Crear registros

  1. Pulsa Nuevo o Nueva.
  2. Rellena los campos obligatorios.
  3. Completa los campos recomendados para evitar documentos incompletos.
  4. Revisa fechas, importes, estado, cliente, empleado o material según el módulo.
  5. Pulsa Guardar.
  6. Comprueba que el registro aparece en la tabla.

Editar registros

  1. Busca el registro.
  2. Selecciona la fila.
  3. Pulsa Editar.
  4. Modifica los campos necesarios.
  5. Guarda.
  6. Verifica el resultado en la tabla.

Borrar o anular

Cuando una pantalla no tiene botón específico de anulación, usa el estado del documento o una observación para dejar constancia. Borra solo registros erróneos, duplicados o de prueba.

  1. Selecciona el registro.
  2. Comprueba si está relacionado con documentos históricos.
  3. Si conviene conservar trazabilidad, cambia estado o añade nota de anulación.
  4. Si debe eliminarse, pulsa Borrar o Eliminar.
  5. Lee la confirmación.
  6. Confirma únicamente si estás seguro.

Previsualizar, imprimir y generar PDF

  1. Selecciona el documento o informe.
  2. Pulsa PDF, Vista previa, Previsualizar o Exportar PDF.
  3. En la vista previa, usa Anterior, Siguiente, Zoom + y Zoom -.
  4. Revisa empresa, cliente, fecha, número, líneas, impuestos y totales.
  5. Si hay errores, vuelve al módulo, edita y genera de nuevo.
  6. Cuando esté correcto, pulsa Imprimir.

Importar y exportar

  1. Para importar, entra en el módulo destino y pulsa Importar.
  2. Selecciona formato y archivo.
  3. Revisa mensajes y resumen.
  4. Comprueba la tabla tras importar.
  5. Para exportar, pulsa Exportar.
  6. Elige formato y destino si se solicita.
  7. Comprueba el archivo generado o el registro de exportación.

4Panel principal

El panel principal es la pantalla de inicio operativo. Resume actividad, muestra recordatorios próximos y sirve como punto de orientación al abrir la aplicación.

Acceder

  1. Pulsa Panel principal en el menú lateral.
  2. Revisa tarjetas de resumen y recordatorios.
  3. Si no aparecen recordatorios, revisa Calendario y preferencias de recordatorios en Configuración.

Qué revisar

Resumen de actividadIndicadores generales del estado de la aplicación y del trabajo registrado.
Próximos recordatoriosEventos o notas del calendario en el período configurado.
Sin recordatoriosIndica que no hay avisos próximos o que el rango configurado no los incluye.

5Clientes

Clientes centraliza personas y empresas usadas en presupuestos, pedidos, albaranes y facturas.

Acceder

  1. En el menú lateral, abre el grupo Clientes.
  2. Pulsa Clientes.
  3. La tabla muestra los clientes registrados.

Tabla de clientes

Nombre y apellidosIdentificación principal del cliente.
TipoPersona, empresa u otra clasificación disponible.
NIF/CIFDato fiscal usado en documentos.
Teléfono / EmailContacto operativo.
Ciudad, dirección y C.P.Datos fiscales, de entrega o contacto.
NotasObservaciones internas.

Crear un cliente

  1. Pulsa Nuevo.
  2. Rellena nombre o razón social.
  3. Completa apellidos si procede.
  4. Selecciona tipo de cliente.
  5. Introduce NIF/CIF, teléfono, email, dirección, C.P. y ciudad.
  6. Añade notas internas si necesitas recordar condiciones o preferencias.
  7. Pulsa Guardar.
  8. Comprueba que aparece en la tabla.

Editar un cliente

  1. Busca el cliente.
  2. Selecciona su fila.
  3. Pulsa Editar.
  4. Actualiza los campos necesarios.
  5. Guarda.
  6. Revisa que los cambios aparecen en la tabla.

Borrar o conservar historial

  1. Selecciona el cliente.
  2. Antes de borrar, comprueba si tiene documentos históricos.
  3. Si tiene facturas, presupuestos o pedidos, conserva el registro y usa notas para indicar baja o no usar.
  4. Si es un duplicado o error, pulsa Borrar.
  5. Confirma solo si no afecta al historial.

Importar clientes

  1. Pulsa Importar.
  2. Selecciona el formato indicado por la aplicación.
  3. Elige el archivo.
  4. Si el archivo contiene columnas nuevas, la aplicación puede crearlas.
  5. Revisa el resumen de importación.
  6. Comprueba la tabla y configura columnas si es necesario.

Exportar clientes

  1. Pulsa Exportar.
  2. Selecciona formato.
  3. Guarda el archivo.
  4. Abre el archivo exportado para comprobar que contiene los datos esperados.

Personalizar columnas en Clientes

  1. Pulsa Columnas.
  2. Usa Añadir para crear campos propios.
  3. Usa Renombrar para cambiar etiquetas.
  4. Usa Ocultar o Mostrar para controlar la tabla.
  5. Vuelve a la tabla y rellena valores si la columna es editable.

6Presupuestos

Presupuestos permite crear ofertas detalladas para clientes, con datos generales, servicios/técnicas, materiales de stock, totales y documento PDF.

Acceder

  1. Abre el grupo Comercial.
  2. Pulsa Presupuestos.
  3. Revisa la tabla de presupuestos registrados.

Pestañas y tablas

Datos generalesCliente, número, fecha, estado, condiciones y observaciones.
Servicios / TécnicasLíneas de trabajo con descripción, técnica, cantidad, precio unitario, descuento y total.
Materiales del stockSelector de material, disponibilidad, precio, cantidad, botón Añadir al presupuesto y total de materiales.

Crear un presupuesto

  1. Pulsa Nuevo.
  2. En Datos generales, selecciona cliente.
  3. Revisa fecha, número y estado.
  4. Añade condiciones u observaciones.
  5. En Servicios / Técnicas, introduce cada trabajo: descripción, técnica, cantidad, precio y descuento.
  6. En Materiales del stock, selecciona material, revisa disponibilidad, indica cantidad y pulsa Añadir al presupuesto.
  7. Comprueba total de servicios, materiales, impuestos y total final.
  8. Guarda.

Editar un presupuesto

  1. Busca el presupuesto.
  2. Selecciona la fila.
  3. Pulsa Editar.
  4. Modifica datos generales, líneas o materiales.
  5. Revisa totales después de cualquier cambio.
  6. Guarda.
  7. Vuelve a generar PDF si ya habías entregado una versión anterior.

Anular o borrar un presupuesto

  1. Selecciona el presupuesto.
  2. Si se envió al cliente, cambia estado o añade observación de anulación en lugar de borrarlo.
  3. Si es prueba o duplicado, usa Borrar.
  4. Confirma la eliminación solo si no necesitas historial.

Previsualizar, imprimir o entregar

  1. Selecciona el presupuesto.
  2. Pulsa PDF o Vista previa.
  3. Revisa cliente, fecha, líneas, materiales, IVA y total.
  4. Usa zoom si necesitas ver detalle.
  5. Imprime o guarda el documento desde la vista previa.

Importar y exportar presupuestos

  1. Para importar, pulsa Importar, selecciona archivo y confirma. Los presupuestos importados se añaden o actualizan.
  2. Para exportar, pulsa Exportar, elige formato y guarda.
  3. Revisa siempre el resultado en la tabla.

7Facturas

Facturas genera documentos de venta con datos de cliente, líneas de servicios, materiales de stock, impuestos, totales y PDF imprimible.

Acceder

  1. En Comercial, pulsa Facturas.
  2. Revisa el listado.
  3. Usa Buscar para localizar facturas por cliente, número o dato visible.

Pestañas

Datos generalesNúmero, serie, cliente, fecha, vencimiento, estado de cobro y observaciones.
Servicios / TécnicasTrabajos facturados con cantidad, precio, descuento e impuestos.
Materiales del stockMateriales añadidos a la factura y total de materiales.

Crear factura

  1. Pulsa Nueva factura o Nuevo.
  2. Selecciona cliente.
  3. Revisa número, serie y fecha.
  4. Añade servicios en Servicios / Técnicas.
  5. Si corresponde, añade materiales desde Materiales del stock con Añadir a la factura.
  6. Comprueba base imponible, descuentos, impuestos y total.
  7. Guarda.

Editar factura

  1. Selecciona la factura.
  2. Pulsa Editar factura o Editar.
  3. Modifica cabecera, servicios o materiales.
  4. Revisa total e impuestos.
  5. Guarda.
  6. Genera de nuevo el PDF si el documento ya estaba emitido.

Anular o borrar factura

Las facturas deben conservar trazabilidad. Si la factura tiene validez fiscal o ya se entregó, no la borres sin criterio administrativo. Usa observaciones, estado o corrección documental según proceda.

  1. Selecciona la factura.
  2. Revisa si fue entregada o cobrada.
  3. Si debe conservarse, cambia estado o añade observación de anulación.
  4. Si es prueba, pulsa Borrar y confirma.

Previsualizar e imprimir factura

  1. Selecciona factura.
  2. Pulsa PDF o Vista previa.
  3. Comprueba datos de empresa, cliente, NIF/CIF, número, fecha, líneas, IVA y total.
  4. Pulsa Imprimir si todo es correcto.

Importar y exportar facturas

  1. Pulsa Importar para añadir o actualizar facturas desde archivo.
  2. Revisa el resumen y la tabla.
  3. Pulsa Exportar para guardar facturas en formato disponible.

8Albaranes

Albaranes documenta entregas de trabajos, artículos o materiales al cliente.

Acceder

  1. En Comercial, pulsa Albaranes.
  2. Consulta la tabla.
  3. Selecciona una fila para editar, borrar, exportar o generar documento.

Crear albarán

  1. Pulsa Nuevo.
  2. En Datos generales, selecciona cliente, fecha, número, dirección y observaciones.
  3. En Artículos, añade líneas entregadas con descripción y cantidad.
  4. Si usas materiales, revisa disponibilidad.
  5. Guarda.

Editar, anular o borrar

  1. Selecciona el albarán.
  2. Pulsa Editar para modificar cabecera o artículos.
  3. Si la entrega se cancela, deja observación o estado si existe.
  4. Borra solo albaranes de prueba o erróneos.

Imprimir o exportar

  1. Selecciona el albarán.
  2. Pulsa PDF o vista previa.
  3. Revisa cliente, artículos y cantidades.
  4. Imprime o guarda.
  5. Para listado externo, pulsa Exportar.

Importar

  1. Pulsa Importar.
  2. Selecciona archivo.
  3. Confirma. Los albaranes importados se añaden o actualizan.
  4. Revisa el resultado en la tabla.

9Pedidos y control de pagos

Pedidos permite controlar trabajos aceptados, estados, importes, entregas y pagos vinculados.

Acceder

  1. En Comercial, pulsa Pedidos.
  2. Usa la pestaña Pedidos para gestionar trabajos.
  3. Usa Control de pagos para cobros y vencimientos.

Crear pedido

  1. Pulsa Nuevo.
  2. Selecciona cliente.
  3. Rellena número, fecha, entrega, descripción, estado, total y observaciones.
  4. Guarda.
  5. Comprueba que aparece en la tabla.

Editar pedido

  1. Busca y selecciona el pedido.
  2. Pulsa Editar.
  3. Actualiza estado, fecha de entrega, total u observaciones.
  4. Guarda.

Anular o borrar pedido

  1. Selecciona el pedido.
  2. Si se canceló, cambia estado o añade observación.
  3. Si nunca fue real, usa Borrar.
  4. Antes de borrar, comprueba si tiene pagos asociados.

Añadir pago

  1. Selecciona el pedido.
  2. Abre la pestaña Control de pagos.
  3. Pulsa Añadir pago.
  4. Introduce importe, fecha, método y observaciones.
  5. Guarda.
  6. Comprueba pagado y pendiente.

Fraccionar y confirmar cobro

  1. Usa Fraccionar pago si el cliente pagará en varios vencimientos.
  2. Cuando recibas dinero, selecciona el pago.
  3. Pulsa Confirmar cobro.
  4. Indica la fecha en que se recibió.
  5. Revisa que el pago pasa a cobrado.

Importar y exportar pedidos

  1. Pulsa Importar para cargar pedidos desde archivo.
  2. Pulsa Exportar para sacar listados.
  3. Revisa pagos y estados tras cualquier importación.

10Tarifas

Tarifas guarda precios por técnica de impresión, servicio, categoría o unidad de trabajo.

Acceder

  1. Abre Almacén.
  2. Pulsa Tarifas.
  3. Revisa precios por técnica.

Crear tarifa

  1. Pulsa Nuevo.
  2. Introduce técnica o servicio.
  3. Añade descripción, precio, unidad, categoría y observaciones.
  4. Guarda.

Editar, borrar, importar y exportar

  1. Para editar, selecciona tarifa y pulsa Editar.
  2. Actualiza precio o descripción y guarda.
  3. Para borrar, selecciona y confirma solo si ya no se usa.
  4. Para importar, pulsa Importar y selecciona archivo.
  5. Para exportar, pulsa Exportar y guarda listado.

11Materiales

Materiales controla stock, proveedores, pagos de compra y reglas de consumo por técnica.

Acceder

  1. Abre Almacén.
  2. Pulsa Materiales.
  3. Elige Stock, Pagos o Consumo por técnica.

Gestionar stock

  1. En la pestaña Stock, pulsa Nuevo para crear material.
  2. Rellena nombre, referencia, proveedor, unidad, precio, stock actual y stock mínimo.
  3. Guarda.
  4. Activa Solo materiales con stock bajo para revisar compras necesarias.

Editar o borrar material

  1. Selecciona material.
  2. Pulsa Editar para corregir stock, proveedor, precio o mínimo.
  3. Guarda.
  4. Borra solo si no forma parte del historial de facturas o consumos.

Registrar pagos de materiales

  1. Abre la pestaña Pagos.
  2. Añade un pago.
  3. Indica proveedor, importe, fecha y notas.
  4. Guarda.
  5. Revisa la tabla de pagos.

Configurar consumo por técnica

  1. Abre Consumo por técnica.
  2. Selecciona técnica y material.
  3. Define cuánto se consume por unidad.
  4. Guarda la regla.
  5. Comprueba estas reglas antes de facturar, porque pueden afectar al stock.

Importar y exportar materiales

  1. Pulsa Importar para cargar inventario.
  2. Revisa columnas y stock.
  3. Pulsa Exportar para guardar listado.

12Empleados

Empleados almacena datos del personal y sirve de base para nóminas.

Acceder

  1. Abre Personal.
  2. Pulsa Empleados.
  3. Usa Buscar o el filtro de empleados dados de baja.

Crear empleado

  1. Pulsa Nuevo.
  2. Rellena nombre, apellidos, documento, teléfono, email, puesto, salario, fecha de alta y observaciones.
  3. Marca Activo si corresponde.
  4. Guarda.

Editar o dar de baja

  1. Selecciona empleado.
  2. Pulsa Editar.
  3. Actualiza datos laborales o contacto.
  4. Para baja, desmarca Activo o registra observación.
  5. Activa Mostrar empleados dados de baja para verlos de nuevo.

Borrar, importar y exportar

  1. Borra solo empleados creados por error.
  2. Importa empleados desde archivo si tienes listado externo.
  3. Exporta para revisión o copia administrativa.

13Nóminas

Nóminas permite registrar y calcular documentos laborales según parámetros salariales.

Acceder

  1. Abre Personal.
  2. Pulsa Nóminas.
  3. Filtra por año y mes si necesitas un período concreto.

Crear nómina

  1. Comprueba antes que el empleado existe en Empleados.
  2. Pulsa Nueva.
  3. Selecciona año, mes y empleado.
  4. Introduce salario base, precio/hora, horas extra normales, horas extra festivas, complementos, no salarial e IRPF.
  5. Revisa cálculos.
  6. Guarda.

Editar, borrar e imprimir

  1. Selecciona nómina.
  2. Pulsa Editar para corregir importes o período.
  3. Borra solo nóminas erróneas o duplicadas.
  4. Pulsa PDF o vista previa para generar documento.
  5. Revisa antes de imprimir.

Importar y exportar

  1. Usa Importar para cargar nóminas desde formato admitido.
  2. Usa Exportar para guardar listados o documentación.

Previsualizar y exportar PDF

15Calendario

Acceder y moverse

  1. Abre Analítica.

Crear y borrar notas

Ver recordatorios en el panel

  3. Comprueba Próximos recordatorios.

16Asistente IA

El Asistente IA permite consultar dudas, redactar textos y apoyarse en contexto de la aplicación mediante Ollama.

Acceder

  1. Abre Sistema.
  2. Pulsa Asistente IA.
  3. Comprueba si Ollama está disponible.

Usar el chat

  1. Escribe tu consulta.
  2. Marca Incluir contexto del ERP si la pregunta está relacionada con la aplicación.
  3. Envía.
  4. Lee la respuesta y verifica datos importantes antes de aplicarlos.

Cuando no responde

  1. Comprueba Ollama.
  2. Instala Ollama si falta.
  3. Revisa que haya un modelo disponible.
  4. Reinicia el servicio si fuese necesario.

17Ollama y gestión de modelos

Instalar Ollama

  1. Desde Asistente IA, pulsa Instalar Ollama.
  2. En el diálogo, pulsa Instalar Ollama.
  3. Deja marcada la opción de asistente visual si quieres acompañamiento.
  4. Observa el registro de progreso.
  5. Cierra cuando finalice.

Gestionar modelos

  1. Abre Gestión de modelos.
  2. Consulta modelos instalados.
  3. Para descargar, marca modelos sugeridos o escribe nombre.
  4. Pulsa Descargar o Descargar seleccionados.
  5. Para liberar espacio, selecciona un modelo instalado y pulsa Eliminar.

18Configuración

Configuración controla apariencia, empresa, preferencias, música e información del sistema.

Apariencia

  1. Abre Configuración.
  2. En Apariencia, elige tema de color.
  3. Activa modo oscuro si lo necesitas.
  4. Selecciona fuente y tamaño.
  5. Pulsa Aplicar tipografía.
  6. Pulsa Guardar cambios.

Mi empresa

  1. Abre la pestaña Mi empresa.
  2. Rellena razón social, NIF, dirección, teléfono, email, web e IBAN.
  3. Añade logo o textos si la pantalla lo permite.
  4. Guarda.
  5. Genera un documento de prueba para comprobar cabecera y pie.

Preferencias

  1. Abre Preferencias.
  2. Ajusta valores por defecto de facturación y presupuestos.
  3. Ajusta recordatorios del calendario.
  4. Pulsa los botones de guardar preferencias correspondientes.

Acerca de

  1. Abre Acerca de.
  2. Consulta versión 10.5.0, sistema e información de soporte.

19Asistente visual

El asistente visual muestra personajes, ayudas, animaciones y voz opcional.

Configurar

  1. Abre Configuración asistente visual.
  2. Marca Mostrar asistente visual.
  3. Selecciona personaje.
  4. Ajusta tamaño.
  5. Marca Leer ayudas por voz si quieres audio.
  6. Marca Mostrar en instalación de Ollama y modelos si quieres verlo dentro del instalador.
  7. Pulsa Restablecer posición si queda mal colocado.

Usar

  1. Mantén visible el asistente durante el trabajo.
  2. Pasa por controles para recibir ayuda contextual.
  3. Usa el botón del menú lateral para activarlo o desactivarlo.

20Reproductor de música

Crear lista de reproducción

  1. Abre Configuración.
  2. Entra en Música.
  3. Pulsa + Añadir MP3.
  4. Selecciona uno o varios archivos.
  5. Haz doble clic en una pista para reproducirla.

Controlar reproducción

  1. Ajusta volumen.
  2. Marca Repetir lista en bucle si quieres reproducción continua.
  3. Marca Reproducir automáticamente al iniciar la aplicación si lo deseas.
  4. Para quitar una pista, selecciónala y pulsa Quitar seleccionado.
  5. Pulsa Guardar configuración de música.

21Exportar / Backup

Crear copia completa

  1. Abre Sistema.
  2. Pulsa Exportar / Backup.
  3. Revisa base de datos activa, tamaño y registros principales.
  4. Pulsa Exportar.
  5. Elige formato si se solicita: SQLite, ZIP CSV, SQL o JSON.
  6. Guarda el archivo.
  7. Revisa el registro de exportación.
  8. Pulsa Abrir carpeta si quieres localizar la copia.

Cuándo hacer backup

Antes de actualizarCrea una copia completa.
Antes de importarHaz backup para poder volver atrás.
Trabajo diarioHaz copia periódica si la aplicación contiene datos importantes.

22Importar Backup

Restaurar copia

  1. Antes de restaurar, crea backup del estado actual.
  2. Abre Importar Backup.
  3. Revisa base actual, tamaño y registros.
  4. Pulsa Importar.
  5. Selecciona archivo de backup.
  6. Lee la advertencia de sustitución de datos.
  7. Confirma solo si el archivo es correcto.
  8. Revisa el registro de importación.
  9. Abre módulos clave para comprobar datos restaurados.
Precaución.
Importar un backup puede reemplazar los datos actuales. No lo hagas sin copia previa.

23Importación de datos con IA

Importar archivo con ayuda de IA

  1. Abre Importación de datos con IA.
  2. Selecciona archivo CSV, TXT, Excel o JSON.
  3. Revisa columnas encontradas.
  4. Pulsa Detectar tipo de datos o elige manualmente clientes, materiales, empleados o tarifas.
  5. Si Ollama está disponible, deja que sugiera mapeo.
  6. En Revisión y ajuste, compara columna del archivo y campo destino.
  7. Corrige asignaciones incorrectas.
  8. Revisa vista previa.
  9. Confirma importación.
  10. Consulta el registro.

Qué revisar antes de confirmar

ClientesNombre, NIF/CIF, email, teléfono, dirección.
MaterialesNombre, stock, unidad, proveedor, precio.
EmpleadosNombre, apellidos, puesto, salario, activo.
TarifasTécnica, descripción, precio, unidad y categoría.

24Columnas dinámicas

Añadir columna

  1. Abre un módulo con botón Columnas.
  2. Pulsa Columnas.
  3. Pulsa + Añadir.
  4. Escribe nombre claro.
  5. Guarda.
  6. Vuelve a la tabla y rellena valores si procede.

Renombrar, ocultar y mostrar

  1. Selecciona la columna.
  2. Pulsa Renombrar para cambiar etiqueta.
  3. Pulsa Ocultar para retirarla de la vista.
  4. Pulsa Mostrar para recuperarla.
  5. Ten en cuenta que ocultar no equivale necesariamente a borrar datos.

25Vista previa PDF

Usar la ventana

  1. Abre un documento desde Presupuestos, Facturas, Albaranes, Nóminas o Estadísticas.
  2. Usa Anterior y Siguiente para cambiar página.
  3. Usa Zoom + y Zoom - para revisar detalles.
  4. Comprueba página actual y total.
  5. Pulsa Imprimir si el documento está correcto.

SituaciónAcción recomendada
No veo un registroLimpia filtros, revisa Buscar y comprueba que estás en el módulo correcto.
No puedo editarSelecciona una fila antes de pulsar Editar.
No sé si borrarNo borres si tiene historial; usa estado o notas.
PDF con datos antiguosActualiza Configuración → Mi empresa y genera de nuevo.
Importación incorrectaRestaura backup previo o corrige mapeo e importa de nuevo.
Ollama no respondeInstala Ollama, revisa modelos o reinicia el servicio.
