1. Primer acceso y autenticación

Primer arranque — Configuración del administrador

La primera vez que se ejecuta la aplicación no existen usuarios. Aparece automáticamente la pantalla de Configuración inicial del administrador. Solo hay que completarla una vez.

  1. Introduce el nombre de usuario del administrador.
  2. Escribe la contraseña (mínimo 6 caracteres). Marca ☐ Mostrar contraseña para verla.
  3. Selecciona una pregunta de seguridad del desplegable (necesaria para recuperar la contraseña si se olvida).
  4. Escribe la respuesta a esa pregunta. La respuesta no distingue mayúsculas ni espacios iniciales.
  5. Pulsa Crear administrador. La aplicación entra directamente al panel principal.
Solo una vez.
Esta pantalla no vuelve a aparecer una vez creado el primer administrador. Guarda la respuesta de seguridad en un lugar seguro: es la única forma de recuperar la contraseña sin un administrador disponible.

Inicio de sesión

  1. Abre la aplicación. Aparece la pantalla de login.
  2. Escribe tu usuario y contraseña.
  3. Marca ☐ Mostrar contraseña si quieres ver lo que escribes.
  4. Pulsa Entrar. Si los datos son correctos, accedes al panel principal.
Credenciales incorrectas.
Si el usuario no existe o la contraseña es incorrecta, aparece un aviso en rojo. Revisa mayúsculas y verifica que el usuario fue creado en Gestión de usuarios.

Recuperar contraseña olvidada

  1. En la pantalla de login, pulsa el enlace ¿Olvidaste tu contraseña?
  2. Selecciona tu usuario en el desplegable. Aparece automáticamente tu pregunta de seguridad.
  3. Escribe la respuesta (no distingue mayúsculas).
  4. Escribe la nueva contraseña y confírmala. Usa el check para verla.
  5. Pulsa Aceptar. Si la respuesta es correcta, la contraseña queda cambiada. Inicia sesión con la nueva.

Última sesión y usuario activo

El menú lateral muestra, bajo el nombre de usuario y su rol, la fecha y hora de la sesión anterior en formato dd/MM/yyyy HH:mm. Si es el primer acceso, indica «Primera sesión».

Preguntas de seguridad disponibles

¿Nombre de tu primera mascota?Todas las cuentas (administrador y usuarios) deben configurar una pregunta. Es el único mecanismo de recuperación sin intervención del administrador.
¿Ciudad donde naciste?
¿Nombre de tu madre?
¿Tu equipo de fútbol favorito?
¿Nombre de tu mejor amigo de infancia?

2. Inicio y navegación

Abrir y moverse

  1. Inicia sesión con usuario y contraseña.
  2. Usa el menú lateral para entrar en cada módulo.
  3. Haz clic en un módulo para abrirlo en el área principal.
  4. Usa ventana aparte si necesitas comparar dos módulos.

Regla básica de tablas

  1. Busca el registro.
  2. Selecciona la fila.
  3. Después usa Nuevo, Editar, Borrar, Importar, Exportar, PDF o Columnas según corresponda.
Datos locales.
Tu base de datos vive en %LOCALAPPDATA%\GraficasMulberry\graficas_mulberry.db. Haz copias frecuentes con Exportar / Backup en formato .db.

3. El flujo comercial completo

El ciclo típico de un trabajo en Gráficas Mulberry recorre cinco pasos. Cada cuadro corresponde a un módulo del menú lateral.

1ClienteAlta en Clientes
2PresupuestoCrear y enviar
3Factura🧾 desde presupuesto aceptado
4Albarán📋 desde factura · ✅ firmar
5CobroPedidos → Control de pagos
De presupuesto a facturaSelecciona el presupuesto, cámbialo a aceptado, pulsa 🧾 Crear Factura. La factura hereda cliente, líneas y materiales. El presupuesto pasa a facturado.
De factura a albaránSelecciona la factura, pulsa 📋 Crear Albarán. Se genera con referencia a la factura. Cuando el cliente firme, usa ✅ Marcar firmado.
Cobrar el trabajoAbre el pedido asociado (o créalo) y registra los pagos en su pestaña Control de pagos. Confirma cada cobro con su fecha real.
Cerrar la facturaCuando todo está cobrado, en Facturas pulsa ✅ Marcar pagada.

4. Estados de los documentos

Cada documento avanza por estados. La columna Estado de la tabla está coloreada por tipo: gris para borrador/pendiente, azul para enviado/proceso, verde para aceptado/firmado/pagado, rojo para rechazado/vencido y morado para facturado.

Presupuestos

borrador→enviado→aceptado/rechazado→facturado

Facturas

pendiente→pagada/vencida/anulada

Albaranes

pendiente→entregado→firmado

Pedidos

pendiente→en proceso→listo→entregado/cancelado

11. Empleados y nóminas

Empleados

AccederPersonal → Empleados.
CrearNuevo → datos personales, contacto, puesto, salario, activo → Guardar.
EditarSeleccionar → Editar → cambiar datos → Guardar.
BajaDesmarcar Activo o añadir observación. Usa Mostrar empleados dados de baja para verlos.

Nóminas

AccederPersonal → Nóminas.
Crear individualNueva → año, mes, empleado, salario base, horas extra, complementos, IRPF → Guardar.
Generar el mes entero⚡ Generar mes para todos → seleccionar mes y año → Aceptar. Crea una nómina por cada empleado activo. Si ya existía esa nómina del mes, se omite.
EditarSeleccionar → Editar → corregir importes → Guardar.
PDFSeleccionar → PDF/Vista previa → revisar → Imprimir.
Cálculo automático.
Bruto = Salario base + Complementos + Horas extra + Percepciones no salariales.
SS Trabajador = 6,35 % de la base · IRPF = % de la ficha · SS Empresa = 29,90 % (no descuenta al trabajador).
Neto = Bruto − SS Trabajador − IRPF.

Contexto ERP del Asistente IA

Marca Incluir contexto del ERP en el chat para que la IA vea tus presupuestos, facturas, top clientes, pedidos, stock y recordatorios al responder. Se cachea 8 minutos.

Actívalo«¿Qué clientes me deben más?», «Hazme un email de cobro», «Resume mi facturación del mes», «¿Qué materiales pido hoy?»
Déjalo desactivado«Redacta un texto comercial», «Tradúceme esto», «Explícame DTF». Más rápido y consume menos memoria.

14. Atajos y consejos exprés

Doble clic filaEn cualquier tabla equivale a Editar.
Ctrl + clicSelecciona varias filas a la vez.
Enter(IA) Envía la consulta. Shift + Enter añade salto de línea.
Ctrl + ASelecciona todas las filas de la tabla activa.
F11Maximizar / restaurar.
Alt + F4Cerrar la aplicación (pide confirmación).

Reglas de oro

  • Antes de cualquier importación o restauración: backup .db.
  • El presupuesto se factura cuando está en aceptado. Cambia el estado antes.
  • Las facturas no se borran: se anulan.
  • «Generar mes para todos» en Nóminas: revisa antes salario base e IRPF en cada ficha.
  • Pasa con frecuencia por Pedidos → Control de pagos para detectar vencidos.
  • Activa contexto ERP en la IA solo cuando la pregunta dependa de tus datos.
  • Guarda la respuesta de seguridad en un lugar seguro: es el único método de recuperación de contraseña autónomo.

15. Problemas frecuentes

No aparece la pantalla de loginSolo ocurre en el primer arranque (aparece el asistente de configuración inicial). Una vez creado el admin, siempre aparece el login.
Credenciales incorrectasComprueba mayúsculas. Si no recuerdas la contraseña, usa «¿Olvidaste tu contraseña?» en el login. Si también olvidaste la respuesta de seguridad, el administrador puede cambiar la contraseña desde Gestión de usuarios.
Respuesta de seguridad no aceptadaLa respuesta se guarda normalizada (sin mayúsculas ni espacios iniciales). Prueba en minúsculas. Si sigue fallando, pide al administrador que cambie la contraseña.
No veo el módulo «Gestión de usuarios»Solo es visible para cuentas con rol ADMINISTRADOR.
No puedo acceder a un móduloTu cuenta no tiene permiso para ese módulo. El administrador puede asignarte acceso desde Gestión de usuarios.
No encuentro un registroLimpia filtros, revisa Buscar y confirma que estás en el módulo correcto.
No puedo editar/borrarSelecciona primero la fila de la tabla.
Importación fallaRevisa formato, columnas y mapeo. Haz backup antes de repetir.
PDF con datos antiguosConfiguración → Mi empresa → actualiza y genera otra vez.
IA no respondeInstala Ollama, descarga al menos un modelo. Para equipos con poca RAM, usa llama3.2.
El asistente visual no apareceMenú lateral → 🧭 Activar asistente, o Configuración asistente visual → Restablecer posición.
Sonidos UI molestanReduce el volumen de interfaz en Configuración. La música tiene volumen independiente.
