Cómo facturar un albarán

  1. Abre el módulo Albaranes.
  2. Selecciona el albarán que deseas facturar (debe estar en estado Entregado).
  3. Haz clic en Generar factura.
  4. El sistema crea una nueva factura con las líneas y datos del albarán.
  5. Revisa y ajusta el IVA o las líneas si es necesario.
  6. Guarda la factura. El albarán pasa automáticamente a estado Facturado.
Un albarán facturado no puede volver a generar otra factura. Si necesitas más líneas, crea una factura nueva manualmente.
