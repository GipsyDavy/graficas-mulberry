Novedades de la versión actual (v13.5)

Importación mejorada — XLSB, XLSM y más formatos Excel

Ahora puedes importar archivos en todos los formatos de Excel:

  • XLSB — Excel Binario (formato compacto de Microsoft Excel)
  • XLSM — Excel con macros (los datos se importan; las macros se ignoran)
  • XLTX / XLTM — plantillas de Excel
  • Además de los ya soportados: XLSX, XLS, CSV, JSON

No necesitas convertir el archivo antes de importarlo. Selecciona el archivo directamente y el asistente de importación lo procesa automáticamente.

Crear campos personalizados desde el asistente de importación

Durante la importación, ahora puedes crear un campo personalizado nuevo directamente en el diálogo de mapeo de columnas, sin tener que salir del flujo de importación.

El botón ➕ Nuevo campo… aparece en la parte inferior del diálogo de mapeo cuando importas clientes, materiales, empleados, pedidos, nóminas o tarifas.

Esta función no está disponible para presupuestos, facturas ni albaranes por su estructura de cabecera + líneas.

Consulta Crear un campo personalizado durante la importación.

Indicadores de carga (skeleton + overlay)

Las tablas de Clientes, Facturas y Pedidos ahora muestran un indicador de carga mientras se recuperan los datos de la base de datos. Esto es especialmente útil cuando la tabla tiene muchos registros.

Mejoras visuales

  • Asistente de IA (IAView) con barra de comandos estilizada.
  • Barra de estado mejorada con variables CSS coherentes en todos los temas.
  • DatePicker, ProgressBar, RadioButton y ContextMenu estilizados de forma coherente.
