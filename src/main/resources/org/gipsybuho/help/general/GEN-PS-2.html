Cómo usar el asistente de bienvenida (configuración inicial guiada)

El asistente de bienvenida es un flujo guiado de pasos para rellenar los datos básicos (empresa, primer cliente, primera tarifa) al empezar a usar la aplicación. Es distinto del asistente visual (el personaje flotante) y del Asistente IA (el chat).

Activarlo

  1. Aparece automáticamente la primera vez que se detecta la aplicación recién instalada.
  2. También puedes invocarlo manualmente: menú Ayuda → Iniciar asistente de configuración.
  3. Sigue los pasos: información de empresa, primer cliente, primera tarifa.
  4. Al finalizar, el asistente se cierra y la aplicación queda lista para usar.
Puedes omitir pasos si ya tienes datos importados, usando el botón Omitir en cada paso. Si lo cierras a mitad, los pasos ya completados quedan guardados, pero el asistente vuelve a empezar desde el principio la próxima vez que lo abras.
