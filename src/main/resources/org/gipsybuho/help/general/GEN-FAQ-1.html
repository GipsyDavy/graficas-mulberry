Preguntas frecuentes generales

¿Puedo usar la aplicación en varios equipos a la vez?

No. La aplicación es monopuesto: la base de datos está en el equipo donde se instala. No hay servidor central ni sincronización automática entre equipos. Si necesitas usar los datos en otro equipo, exporta un backup e impórtalo allí.

¿Los datos se guardan en la nube?

No. Todos los datos se almacenan en el equipo local, en la carpeta %LOCALAPPDATA%\GraficasMulberry\. No se envía ningún dato a internet, ni siquiera al usar el asistente de IA (Ollama también es local).

¿Qué hago si la aplicación no arranca?

  1. Verifica que tienes Java 21 o superior instalado.
  2. Cierra cualquier otra instancia de la aplicación que pudiera estar abierta.
  3. Si el error menciona la base de datos, haz una copia de seguridad del archivo %LOCALAPPDATA%\GraficasMulberry\graficas_mulberry.db antes de continuar.
  4. Contacta con el administrador del sistema si el error persiste.

¿Puedo cambiar mi contraseña?

Sí. Ve a Configuración → Mi cuenta y elige la opción de cambiar contraseña. Necesitas introducir la contraseña actual para confirmar el cambio. Si has olvidado tu contraseña, un ADMINISTRADOR puede restablecerla desde Usuarios.

¿Puedo eliminar registros?

Sí, pero ten en cuenta que algunas eliminaciones son irreversibles si no tienes un backup reciente. Consulta Acciones irreversibles: qué se puede recuperar y qué no.

¿La aplicación funciona sin internet?

Sí. La aplicación es completamente offline. Solo necesita internet si quieres descargar modelos de IA para Ollama, que es un proceso manual y opcional.

¿Cómo sé qué versión tengo instalada?

La versión aparece en la parte inferior de la barra lateral izquierda.
