Glosario de términos del sistema

TérminoDefinición
AlbaránDocumento que acredita la entrega de mercancía o prestación del servicio. Se genera normalmente desde una factura.
BackupCopia de seguridad de la base de datos. Permite restaurar todos los datos en caso de pérdida o error grave.
Campo obligatorioCampo que debe rellenarse para guardar el registro. Se indica con un asterisco (*) o en rojo si se deja vacío.
Clave primariaIdentificador único de un registro (NIF para clientes, DNI para empleados, código para materiales). No puede repetirse.
Columna dinámicaCampo adicional creado por el usuario (p. ej. "Sector" en clientes). Se almacena como columna extra en la tabla correspondiente.
DNIDocumento Nacional de Identidad del empleado. Clave única que identifica a cada empleado en el sistema.
DuplicadoRegistro con la misma clave primaria que otro ya existente. El sistema puede omitirlo, actualizarlo o crear uno nuevo según la política elegida.
EstadoFase actual de un documento: p. ej. un presupuesto puede estar en borrador, enviado, aceptado o rechazado.
FacturaDocumento fiscal que acredita la compraventa de bienes o servicios. Se genera desde un presupuesto aceptado o directamente.
FK (clave foránea)Referencia de un documento a otro (p. ej. una factura referencia al cliente por su NIF). Si el registro referenciado no existe, el sistema devuelve un error.
IVAImpuesto sobre el Valor Añadido. Se aplica como porcentaje sobre la base imponible de presupuestos y facturas.
LíneaFila de detalle dentro de un presupuesto, factura, albarán o pedido. Describe un concepto, cantidad y precio unitario.
Mapeo de columnasProceso de asignar cada columna del archivo importado a un campo del sistema. Se realiza en el diálogo de importación.
NIFNúmero de Identificación Fiscal del cliente. Clave única que identifica a cada cliente en el sistema.
NóminaRegistro mensual del salario de un empleado: salario bruto, retenciones y neto a percibir.
PedidoSolicitud de compra de materiales a un proveedor.
Política de duplicadosComportamiento del sistema cuando importa un registro cuya clave ya existe: Omitir, Actualizar o Crear nuevo.
PresupuestoOferta económica detallada enviada al cliente. Cuando se acepta, se convierte en factura.
RolConjunto de permisos asignados a un usuario: ADMINISTRADOR, COMERCIAL, PRODUCCION o CONTABILIDAD.
StockCantidad disponible de un material en almacén. Se actualiza cuando se recibe un pedido.
TarifaPrecio especial acordado entre la empresa y un cliente para un material concreto. Puede tener tramos por cantidad.
TTSTexto a Voz (Text To Speech). Función del asistente visual que lee en voz alta el contenido de la pantalla.
TramoRango de cantidad dentro de una tarifa. A mayor cantidad comprada, menor precio unitario.
