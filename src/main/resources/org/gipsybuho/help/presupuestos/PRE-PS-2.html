Cómo convertir un presupuesto en factura

Solo se puede convertir a factura un presupuesto en estado Aceptado. Cambia primero el estado si es necesario.
  1. Abre el módulo Presupuestos.
  2. Selecciona el presupuesto en la tabla.
  3. Cambia su estado a Aceptado si todavía está en Borrador o Enviado.
  4. Haz clic en el botón Generar factura (icono de factura en la barra de herramientas).
  5. El sistema crea una nueva factura con las mismas líneas y datos del presupuesto.
  6. Revisa la factura generada y guárdala si todo es correcto.
El presupuesto original no se elimina ni se modifica. Queda vinculado a la factura generada para trazabilidad.
