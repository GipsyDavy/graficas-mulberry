Error: NIF duplicado

Aparece cuando intentas crear un cliente con un NIF que ya existe en el sistema.

Cómo resolverlo

  1. Busca el NIF en la tabla de clientes usando el campo de búsqueda.
  2. Si el cliente ya existe y es el mismo, no necesitas crear uno nuevo. Edita el existente si quieres actualizar datos.
  3. Si crees que el NIF es nuevo pero el sistema lo rechaza, verifica que no tiene espacios ni guiones adicionales.
  4. Si estás importando y aparece en el resumen como "omitido por duplicado" con política Omitir, es el comportamiento esperado: el cliente ya existía.
