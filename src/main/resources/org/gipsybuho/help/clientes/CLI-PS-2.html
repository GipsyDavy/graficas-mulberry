Cómo editar los datos de un cliente

  1. Abre el módulo Clientes.
  2. Localiza al cliente en la tabla (usa el campo de búsqueda si hay muchos).
  3. Haz doble clic sobre la fila, o selecciónala y pulsa el botón ✏️ Editar.
  4. Modifica los campos que necesites.
  5. Haz clic en Guardar.
El NIF no se puede cambiar directamente porque es la clave de todos los documentos del cliente. Si hay un error en el NIF, contacta con el administrador del sistema.
