Preguntas frecuentes sobre tarifas

¿Puedo asignar una tarifa diferente a cada cliente?

Sí. Cada cliente puede tener su propia tarifa asignada. Si no tiene ninguna, se usa el precio base de cada material.

¿Qué pasa si borro un material que tiene precio en una tarifa?

La línea de esa tarifa referente al material eliminado se huerfanará. Revisa y limpia las tarifas manualmente en ese caso.

¿Puedo duplicar una tarifa para crear una variante?

Sí. Selecciona la tarifa y usa el botón Duplicar. La nueva tarifa hereda todas las líneas de precio.

¿Puedo eliminar una tarifa asignada a clientes?

El sistema no permite eliminar una tarifa mientras haya clientes asignados a ella. Reasigna primero a esos clientes a otra tarifa.
