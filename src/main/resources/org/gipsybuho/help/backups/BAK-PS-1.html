Cómo hacer una copia de seguridad

Un backup guarda una copia de toda la base de datos en un archivo que puedes guardar donde quieras (pendrive, carpeta compartida, nube). Es la única forma de recuperarse de un error grave o de una importación incorrecta.

  1. En la barra lateral, haz clic en Importar / Exportar.
  2. Abre la pestaña Backup.
  3. Haz clic en Exportar backup.
  4. Elige una carpeta donde guardar el archivo. El sistema genera un nombre con la fecha: backup_graficas_mulberry_YYYYMMDD_HHMMSS.zip.
  5. Confirma. En unos segundos verás el mensaje de éxito.
Guarda los backups en una carpeta fuera del equipo (pendrive o carpeta de red) para protegerte de fallos del disco duro.

¿Qué incluye el backup?

El backup incluye toda la base de datos: clientes, materiales, empleados, presupuestos, facturas, albaranes, pedidos, nóminas, tarifas, configuración y columnas personalizadas.

Los archivos adjuntos (PDFs, imágenes) exportados fuera de la app no se incluyen.
