Restaurar un backup sobreescribe todos los datos actuales

Restaurar un backup elimina permanentemente el estado actual de la base de datos y lo reemplaza por el del backup. No hay marcha atrás salvo que hayas hecho un backup del estado actual antes de restaurar.

Qué se pierde al restaurar

  • Todos los registros creados o modificados después de la fecha del backup.
  • Facturas, presupuestos, clientes o cualquier dato introducido desde entonces.
  • La configuración de columnas personalizadas creadas después del backup.

Protocolo seguro antes de restaurar

  1. Haz un backup del estado actual (Cómo hacer una copia de seguridad).
  2. Guárdalo en una ubicación diferente a los backups habituales (p. ej. el escritorio).
  3. Ahora restaura el backup antiguo.
  4. Si el resultado no es el esperado, puedes volver al estado que tenías restaurando el backup que acabas de crear.
