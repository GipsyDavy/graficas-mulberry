Cómo restaurar desde una copia de seguridad

Restaurar un backup reemplaza todos los datos actuales por los del backup. Esta acción es irreversible. Si tienes datos recientes que quieres conservar, haz primero un backup del estado actual antes de restaurar.
  1. En la barra lateral, haz clic en Importar / Exportar.
  2. Abre la pestaña Backup.
  3. Haz clic en Importar backup.
  4. Selecciona el archivo .zip del backup que quieres restaurar.
  5. Confirma la advertencia. El sistema restaura la base de datos y reinicia la conexión.
  6. Cierra y vuelve a abrir la aplicación para que todos los módulos se recarguen correctamente.

El backup que quiero no existe

Si no tienes un backup reciente, no es posible recuperar los datos perdidos dentro de la aplicación. En casos excepcionales, un técnico puede intentar recuperar el archivo de base de datos del sistema desde %LOCALAPPDATA%\GraficasMulberry\, pero esto no está garantizado.

Establecer una rutina de backup semanal (o antes de cada importación masiva) elimina prácticamente cualquier riesgo de pérdida de datos.
