Error al importar backup: formato incompatible

¿Por qué aparece este error?

Este error aparece cuando el archivo de backup no es compatible con la versión actual de la aplicación. Las causas más habituales son:

  • El backup fue creado con una versión muy antigua de la aplicación.
  • El archivo está dañado o incompleto (descarga interrumpida, error de copia).
  • El archivo no es un backup de Gráficas Mulberry (se eligió el archivo equivocado).

Cómo resolverlo

  1. Verifica que el archivo seleccionado es el correcto. Debe tener extensión .zip y nombre similar a backup_graficas_mulberry_*.zip.
  2. Comprueba que el archivo no está dañado: el tamaño debe ser razonable (al menos varios KB) y debe poder abrirse con un descompresor ZIP.
  3. Si tienes varios backups, prueba con el más reciente que funcione.
  4. Si el backup fue creado con una versión muy antigua, contacta con el administrador del sistema para valorar la migración.
Los backups creados con versiones anteriores de la aplicación pueden restaurarse en la mayoría de los casos. Si el error persiste, el administrador puede intentar la migración manual de la base de datos SQLite.
