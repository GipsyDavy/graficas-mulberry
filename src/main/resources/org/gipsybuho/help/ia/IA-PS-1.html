Cómo activar y usar la IA integrada (Ollama)

La integración con IA requiere que Ollama esté instalado y en ejecución en el equipo local. No requiere conexión a internet.
  1. Instala Ollama en el equipo (ollama.com) y descarga al menos un modelo (por ejemplo, ollama pull llama3).
  2. Asegúrate de que Ollama está en ejecución: abre una terminal y ejecuta ollama serve, o verifica que el servicio esté activo.
  3. En Gráficas Mulberry, abre Configuración → IA.
  4. Introduce la URL de la API de Ollama (por defecto: http://localhost:11434).
  5. Selecciona el modelo que deseas usar.
  6. Haz clic en Guardar y luego en Probar conexión.
  7. Si la prueba es correcta, el módulo IA queda habilitado.
Para un uso básico, el modelo llama3 ofrece buena relación entre velocidad y calidad. Usa modelos más pequeños (llama3:8b) en equipos con menos memoria RAM.
