Error: código de material duplicado

El código que intentas usar ya existe en otro material del sistema.

Cómo resolverlo

  1. Busca el código en la tabla de materiales para confirmar que ya existe.
  2. Si es el mismo material, edita el existente en lugar de crear uno nuevo.
  3. Si es un material distinto, elige un código diferente y más específico.
