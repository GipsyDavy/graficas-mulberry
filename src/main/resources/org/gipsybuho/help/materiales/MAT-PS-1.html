Cómo añadir un material nuevo

  1. Abre el módulo Materiales.
  2. Haz clic en ➕ Nuevo.
  3. Rellena: Código * (identificador único, p. ej. PAP-A4-80), Nombre *, categoría, unidad de medida, precio y stock inicial.
  4. Haz clic en Guardar.
El código es el identificador único del material. Usa un sistema coherente (p. ej. tipo-formato-gramaje) para facilitar las búsquedas.
