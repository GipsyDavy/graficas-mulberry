Cómo ver las estadísticas de ventas

  1. Abre el módulo Estadísticas.
  2. Selecciona el período: semana, mes, trimestre, año o rango personalizado.
  3. Elige el tipo de gráfica: barras, líneas o circular.
  4. Opcionalmente, filtra por cliente o por tipo de documento (facturas, presupuestos, pedidos).
  5. El panel muestra los totales facturados, número de documentos y comparativa con el período anterior.
Haz clic en una barra del gráfico para ver el detalle de las facturas de ese período.
