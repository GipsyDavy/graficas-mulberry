Preguntas frecuentes sobre usuarios

El módulo de usuarios está desactivado en esta versión. Las respuestas son orientativas para versiones futuras.

¿Cómo recupero mi contraseña?

Cuando la autenticación esté activa, el administrador podrá restablecer la contraseña desde Configuración → Usuarios.

¿Puede un usuario con rol Operador eliminar datos?

No. Solo el rol Administrador puede eliminar registros.

¿Cuántos usuarios se pueden crear?

No hay límite definido. Todos los usuarios comparten la misma base de datos local.
