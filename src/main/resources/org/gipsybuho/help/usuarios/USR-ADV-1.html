Advertencias sobre gestión de usuarios

El módulo de usuarios está desactivado en esta versión. Esta página es informativa.
Nunca compartas la contraseña del administrador. El administrador tiene acceso total a todos los datos, incluyendo la configuración de la empresa y la base de datos.
Eliminar un usuario es una acción irreversible. Todos los datos asociados al usuario (registros de actividad, preferencias) se perderán.
  • Mantén siempre al menos un usuario con rol Administrador activo.
  • Cambia las contraseñas temporales inmediatamente tras la creación del usuario.
  • Revisa periódicamente los usuarios activos y desactiva los que ya no necesites.
