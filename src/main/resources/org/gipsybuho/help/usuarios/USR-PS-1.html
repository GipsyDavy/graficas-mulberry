Cómo gestionar usuarios de la aplicación

Actualmente la autenticación y los permisos por usuario están desactivados en esta versión. Esta sección es informativa para cuando la funcionalidad esté disponible.

Cuando la gestión de usuarios esté activa, el flujo será:

  1. Abre Configuración → Usuarios.
  2. Haz clic en ➕ Nuevo usuario.
  3. Introduce el nombre de usuario, el correo y asigna un rol (Administrador, Operador, Solo lectura).
  4. El sistema enviará al nuevo usuario un correo con la contraseña temporal.
  5. Haz clic en Guardar.
