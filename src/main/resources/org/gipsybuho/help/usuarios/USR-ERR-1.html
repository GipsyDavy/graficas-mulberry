Errores en el módulo de usuarios

El módulo de usuarios está desactivado en esta versión. Esta página es informativa.

«El nombre de usuario ya existe»

Elige un nombre de usuario diferente. Los nombres de usuario deben ser únicos en el sistema.

«Contraseña demasiado corta»

La contraseña debe tener al menos 8 caracteres.

«No puedes eliminar el único administrador»

El sistema siempre debe tener al menos un usuario con rol Administrador. Crea otro administrador antes de eliminar el actual.
