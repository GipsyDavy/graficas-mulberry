Error: NIF o número no encontrado al importar

¿Qué significa este error?

Al importar facturas, albaranes o presupuestos, el sistema necesita saber a qué cliente o proveedor pertenecen. Lo hace buscando el NIF del cliente en la base de datos. Si el NIF indicado en el archivo no existe en el sistema, aparece este error.

Ejemplo de mensaje: NIF "B12345678" no encontrado para el cliente

Causas habituales

  • El cliente aún no está dado de alta en el sistema.
  • El NIF en el archivo tiene un formato diferente al registrado (p. ej. con espacios, guiones o diferente capitalización).
  • El archivo tiene una columna de NIF incorrectamente asignada a otro campo en el mapeo.

Cómo resolverlo

  1. Anota el NIF o número que aparece en el error.
  2. Ve al módulo Clientes y busca si existe ese NIF. Usa el campo de búsqueda.
  3. Si no existe: primero importa o da de alta el cliente, luego vuelve a importar el archivo original.
  4. Si existe pero con diferente formato (p. ej. b12345678 vs B12345678): corrige el NIF en el archivo antes de importar.
  5. Si el error es de número (p. ej. Factura FAC-001 no encontrada al importar un albarán): primero importa las facturas, luego los albaranes.
El orden de importación correcto para documentos vinculados es: Clientes → Presupuestos → Facturas → Albaranes. Nunca importes un documento que referencia otro antes de haber importado el referenciado.
