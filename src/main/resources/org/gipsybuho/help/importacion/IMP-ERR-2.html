Errores de formato de fecha en columnas de fecha

¿Qué formatos de fecha acepta el sistema?

El sistema acepta estos formatos automáticamente:

  • YYYY-MM-DD — formato ISO (recomendado): 2026-05-01
  • Número serial de Excel (p. ej. 46378) — Excel almacena las fechas como días desde 1900.

Formatos que causan errores

  • 01/05/2026 — formato DD/MM/YYYY. Convierte a ISO: 2026-05-01
  • 01-05-2026 — formato DD-MM-YYYY. Mismo problema.
  • May 1, 2026 — fecha en inglés. Convierte a ISO.
  • 01/05/26 — año de dos dígitos. El sistema no puede adivinar el siglo correctamente.
  • Celdas de texto que parecen fechas pero no son fechas de Excel.

Cómo corregirlo en Excel

  1. Selecciona la columna de fechas.
  2. Haz clic derecho → Formato de celdas.
  3. Elige Texto y luego aplica este formato personalizado: YYYY-MM-DD.
  4. O usa la función de Excel: =TEXTO(A1,"YYYY-MM-DD") y copia los resultados como valores.
  5. Guarda el archivo y vuelve a importar.
Si tu archivo Excel tiene las fechas como fechas reales de Excel (no como texto), el importador las convierte automáticamente. El problema solo ocurre cuando la celda tiene la fecha como texto con formato no reconocido.
