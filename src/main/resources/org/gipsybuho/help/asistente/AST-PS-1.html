Cómo usar el asistente visual

El asistente visual aparece automáticamente cuando se detecta que la aplicación está recién instalada o cuando el usuario lo invoca manualmente desde el menú de ayuda.

Activar el asistente

  1. Haz clic en el menú Ayuda en la barra de menú superior.
  2. Selecciona Iniciar asistente de configuración.
  3. Sigue los pasos del asistente: información de empresa, primer cliente, primera tarifa.
  4. Al finalizar, el asistente cierra y la aplicación queda lista para usar.
Puedes omitir pasos del asistente si ya tienes datos importados. Usa el botón Omitir en cada paso.
