Errores frecuentes en el módulo de facturas

«Debe seleccionar un cliente»

El campo Cliente es obligatorio. Busca el cliente por nombre o NIF antes de guardar.

«La factura no tiene líneas»

Una factura debe tener al menos una línea. Añade una línea con descripción, cantidad y precio antes de guardar.

«No se puede editar una factura anulada»

Las facturas anuladas no se pueden modificar. Si fue un error, crea una nueva factura y contacta con soporte técnico para anular el registro incorrecto.

«El IVA introducido no es válido»

El porcentaje de IVA debe ser un número entre 0 y 100. Valores habituales: 0%, 4%, 10%, 21%.
